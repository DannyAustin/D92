# D92 - UNC Charlotte Latest News

A Single Page Application (SPA) that displays the latest news from UNC Charlotte, featuring JWT authentication and interactive data visualizations.

## Features

- JWT-based authentication
- Responsive Single Page Application
- Dynamic data visualizations using D3.js
- WCAG accessibility compliance
- Decoupled frontend and backend architecture

## Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT
- **Data Visualization**: D3.js
- **Web Server**: NGINX

### Prerequisites
